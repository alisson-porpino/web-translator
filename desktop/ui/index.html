Advanced

Each character is drawn with the first font in this list that has a glyph for it — a built-in Japanese fallback is always tried last, so CJK text still renders even with an empty or Latin-only stack. Order matters: put your main lettering font first, a kanji font after it, and so on. Leave the list empty for the built-in font. For an authentic comic look, buy/download Anime Ace or Wild Words yourself (personal-use licenses exist) and point an entry at the .ttf file on your disk — this app never bundles or redistributes those.

Caps how many threads llama.cpp/ONNX Runtime use per inference call. 0 = no cap (use every core). Applies to new jobs right away, no restart needed.

Hard cap on this app's memory use (macOS/Linux only — no effect on Windows yet). A job that would cross it fails instead of letting the whole machine start swapping. 0 = no cap.

There's no OS-level way to cap GPU memory the way the CPU/RAM caps above do, so this is an estimate: fewer of a model's layers get offloaded to the GPU to fit this budget, the rest run on CPU instead (slower, and counted against the memory cap above, not this one). 0 = no budget, offload every layer (today's default). Takes effect the next time a model loads — changing it with a model already loaded reloads it.
