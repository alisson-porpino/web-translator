Engine

The local engine (Koharu's own pipeline) is fully offline, free, and multilingual. Google (Gemini) also reads any language but costs API quota.

Local engine models (Koharu)

A smaller/more-quantized model is faster and uses less RAM but may translate less accurately; a larger one is slower but more capable. Picking a quantization not already downloaded (marked below) triggers a one-time download on the next job.

These all come straight from Koharu's own engine and are saved to its shared config file (~/.koharu/config.toml) — the same one its own desktop app uses, if you ever install it. Takes effect on the next translation job, no restart needed. Koharu also supports several cloud translation providers (OpenRouter, Claude, Grok, etc.) — not exposed here, since this app's own Engine/Google settings above already cover local-vs-cloud.

Advanced

Each character is drawn with the first font in this list that has a glyph for it — a built-in Japanese fallback is always tried last, so CJK text still renders even with an empty or Latin-only stack. Order matters: put your main lettering font first, a kanji font after it, and so on. Leave the list empty for the built-in font. For an authentic comic look, buy/download Anime Ace or Wild Words yourself (personal-use licenses exist) and point an entry at the .ttf file on your disk — this app never bundles or redistributes those.

If the server is running, stop and start it again (above) after changing this for it to take effect.

How confident the text detector must be before counting something as text (0-1). Lower catches more but noisier regions; higher is stricter and may miss faint/unusual lettering. Default 0.3.

Caps how many threads the local text detector (ONNX Runtime) uses — only applies to the Google engine path; the local Koharu engine manages its own resources. 0 = no cap (use every core). Applies to new jobs right away, no restart needed.

Hard cap on this whole app's memory use (macOS/Linux only — no effect on Windows yet). A job that would cross it fails instead of letting the whole machine start swapping. 0 = no cap.

Where the Koharu engine downloads and keeps its models. Useful to point at a different disk if your system drive is low on space. Changing this requires restarting the app — the engine only reads this setting once, at first use after launch.
